LiberCast · Public beta

Your IPTV, without the clutter.

LiberCast is a free, open-source IPTV player for Windows. It's modern, fast and respectful of your provider's limits. You bring your own playlist. LiberCast doesn't host, sell or link to any content.

Download the beta View on GitHub

Features

Your sources

Xtream Codes accounts and M3U playlists, with multiple profiles.

Live TV + EPG

Channel groups, favourites and a programme guide that shows what's on now and next.

Movies & Series

Browse VOD libraries with posters, seasons and resume playback.

Record & download

Record live channels and download VOD for offline viewing.

Connection-aware

Uses as few concurrent connections as possible, for providers with strict limits.

3 languages

English, Turkish and German, switchable in Settings.

Built in the open

LiberCast is built with Electron, React and TypeScript. The code is public, issues are public and contributions are welcome. Claude Code is part of the development workflow, which lets a solo founder ship a polished desktop app quickly.

Legal note

LiberCast is a media player only. It includes no channels, playlists or subscriptions. Use it only with content you're entitled to access.
