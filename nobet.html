nöbet · public beta

Your servers' night watch.

nöbet ("night watch" in Turkish) is a small open-source terminal app. It connects to your Linux servers over SSH and shows their security posture on one screen. It's built for teams with fewer than 50 servers who need answers, not a full security platform.

View on GitHub Get in touch

What it checks

SSH & sudo

Root login, password authentication, key policy, and who can become root and how.

Open ports

What is listening, on which interface, and which process owns it.

Critical updates

Pending security patches and how long they have been waiting.

User access

Accounts, authorized keys and stale users who still have a way in.

Local or remote

Run it on the host itself, or point it at one or many servers over SSH.

No agents

Nothing to install on your servers. If you can SSH in, nöbet can check it.

Why another security tool?

Wazuh and OpenSCAP are excellent, but they're a lot to deploy and run for a team with a handful of servers. nöbet aims for the opposite: one tool, one command, a clear answer in your terminal.

Design principles

  • Read-only by default: nöbet reports, you decide
  • Clear severity labels that don't depend on colour alone
  • Works in any terminal, including with NO_COLOR
